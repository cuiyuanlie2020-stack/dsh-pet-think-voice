# `lib/app/` — 应用层

> 归属：`docs/DESIGN.md` §4.3 四层模型的**【② 应用】**。

## 职责：编排

把领域层的纯逻辑与基础设施层的适配器串成一条完整流程（DESIGN §4.2）：

```
采集 → 切分 → 筛选 → 拟人化 → 节流 → 合成 → 下发
```

| 落点 | 职责 | 排期 |
|---|---|---|
| `app/pipeline` | 编排上述七步，持有状态与生命周期 | P2-6 |
| `app/settings` | 用户可调项（频率档、静音、音色、节流档位） | P3-6 |

## ⛔ 禁止

- **直接调外部 API**（网络、DSH 内部接口）——必须经 `lib/infra/`
- 写文本切分/打分类逻辑——那是 `lib/core/` 的
- 被 `lib/core/` 或 `lib/infra/` 反向引用

## 🔒 必须承接的红线

| 红线 | 应用层的责任 |
|---|---|
| **R5 可一键停** | 静音 / 暂停 / 关闭三个状态必须真正切断后续步骤（不是把音量调 0） |
| **R3 零本地依赖** | TTS 不可用时降级为**只显示气泡文字**，且**必须留痕提示**，不得静默 |
| **R1 不竞争** | 负载闸触发时自动转静默、回落自动恢复 |
