## 4. ⚠️ 本实验最重要的教训：`顺手` 的"收了又剔"与**抽样偏差**

`顺手` 是 DF 最高的候选之一（252），最初抽样（`--show 顺手` 前 12 条）**全部**是
`顺手修个 bug` / `顺手删` / `顺手补上` 这类自我开脱 ⇒ 当时判定"强候选"。

但**随机抽样后翻案**：

| 视角 | 结果 |
|---|---|
| `--show` 前 12 条（**有偏**） | 12/12 像自语 |
| **随机** 12 条（纯本桶片段） | 约 6/12 是**写稿时引用别人的话**（`选顺手的用` / `祝你用得顺手`）或**待办清单续行**（`岁数标题顺手修改`） |
| 它的**新增过阈贡献** | 仅 **+61~85 条**（多数命中片段本来就靠别的信号过阈） |

⇒ **收益小、污染大，剔除。**

**根因**：`emotion-probe --show` 打印的是语料里的**前若干条**，而语料按会话顺序排列
⇒ **同一类用法会连续扎堆**，前 N 条会给出严重有偏的印象。
**结论：任何"抽样看原文"都必须是随机抽样。** 工具已改为固定种子洗牌
（`p0/out/candid-samples.mjs`）。

## 5. 顺带发现的真缺陷：**行内编号清单会被朗读**

随机抽样时发现这类片段：

```
最终回复要包含：1. 结果（删了什么、保留什么、空间）2. 坦白回收站被清空这件事（关键）3. 遗留
```

念出来是"一点 结果… 二点 坦白… 三点 遗留"—— 与 P4-1 修掉的 Markdown 标题**同类**，
但形态不同：标题在**行首**（切分器能剥），这是**同一行内**的编号（多行合并后就长这样）。

- 修法：`interest-scorer` 新增降噪 —— 行内编号 **≥3 个** ⇒ **扣 0.2**
- 判据用**数量**而非"出现即判"：`2.5 分钟` / `第 2 条` / 单个编号都不受影响
- ⚠️ 踩坑：第一版判据写成 `(?:^|\s)\d{1,2}[.)、]\s+`（要求前面是空格）——
  中文里编号前面常是 `：`/`）`，结果**一个都没匹配上**；改用**后行断言排除小数**
- **效果**：6771 条命中该规则，其中 **651 条**原本会过阈（≈ 全部是回复大纲/待办列表）；
  随机抽查 12 条 **12/12 确为清单，零误杀**

## 8. 结论

- ✅ 收「手滑·坦白」**10 词**，权重 0.28，表情 **流汗**（模型 20 个表情里此前完全没用上的那个）
- ❌ 不收 `顺手`（随机抽样翻案）/ `认了` / `看错` / `改错` / `忘记` / `删多` / `大意` / `漏了` /
  `承认` / **`整错`** / **`弄错`**（后两个是**收进表之后**补抽样才抓出来的，见 §4.1）
- ✅ 顺带修掉「行内编号清单会被朗读」（比新桶本身价值更大）
- ✅ **D17 已解**（用户拍定：遵循 R2，不念别人说的话）：新增两条结构判据
  ——「整段被配对引号包住」（9 条）与「以引号开头未闭合」（44 条）⇒ 拒收；
  **否掉了更彻底的「引号奇数即拒收」**（695 条会误杀优质自语，见 §9）

## 9. D17：不念"别人说的话"（用户 2026-10-11 拍定）

三条候选判据，先称代价再定（`p0/out/quote-audit.mjs`）：

| 判据 | 过阈命中 | 随机抽样结论 | 取否 |
|---|---|---|---|
| **R1 整段被同一类配对引号包住** | **9** | 全是引文：`"用三句话解释：为什么并发写入…"`（复述用户问题）· `"你听到的『分支』『贡献者』…"`（草拟给用户的回复） | ✅ |
| **R3 以引号开头且未闭合** | **44** | 全是引文残段：`" got the labels wrong.` | ✅ |
| ~~R2 引号数量为奇数~~ | ~~695~~ | ❌ 命中的几乎全是「模型在思考中引用了用户的话或代码」，**那恰恰是好素材** | ❌ |

⇒ **引号出现 ≠ 引文**。只有引号**把整段包住**、或**从开头就没闭合**时才是引文。

**实测**：拒收 225 → **271（+46）**，与判据命中数吻合。

⚠️ **诚实边界**：**无引号的口播稿正文**（`第三笔，做旅行攻略：…说实话，…`）**判不掉** ——
没有可靠结构特征，硬判会误杀自语。这类污染的主要来源 `顺手` 已从词表剔除；
剩下的部分留 P4-5 用真实听感决定。
