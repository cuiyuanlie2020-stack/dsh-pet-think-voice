# 实验 P4-1 · 触发词表中文重校（D2 / D11）

> 分支：`fix/p4-1-zh-lexicon` · 日期：2026-10-11 · 状态：**已完成，待合并**

## 1. 为什么要做这个实验

D11 的真机现象：**默认配置（中文注入开启）下宠物永远没声音**。

```
宿主日志：语言注入：已开启（zh）
        → 思考流水线：片段=8 过阈=0 最高分=0.29/阈值0.5
对照实验：把语言策略切成 auto（思考回英文）→ 立刻出高分片段并成功出声
```

⇒ 链路本身没问题，问题在**校准口径**：现词表与阈值 0.50 都是**英文语料**校准的，
而注入生效后思考变成中文。用户 2026-10-11 拍板：**重校中文词表、保持「默认中文」**。

## 2. 假设

| # | 假设 | 结论 |
|---|---|---|
| H1 | 阈值 0.50 太高，降阈值即可 | ❌ **被推翻**。真正的问题是词表本身大半没用 |
| H2 | 中文词表需要更多中文词 | ✅ 成立，但**必须按实测 DF 挑**，不能凭想象 |
| H3 | 中英文的"有戏"是同一套信号的翻译 | ❌ **被推翻**。两者不是一个体系（见 §4） |

## 3. 方法（E1~E4 已遵守：从 main 拉分支 / 一次只改词表这一个变量）

```bash
# ① 从会话日志裁中文语料（多帧 zstd，必须 read_across_frames=True）
<bench-py> p0/dump-zh-corpus.py          # → p0/out/corpus-zh.jsonl（不入库）
# ② 中文口径全量诊断：语种 / 逐词 DF / 分位 / 通过率 / 未过阈归因
<node>     p0/zh-calibrate.mjs
# ③ 逐个候选词实测 DF（防止"再写一批僵尸词"）
<node>     p0/zh-marker-probe.mjs        # 第一轮候选
<node>     p0/zh-marker-probe2.mjs       # 第二轮（读原文后手挑）
# ④ 全量口径护栏（正例能否过闸 + 噪声是否被压住）
<node>     p0/calibrate-scorer.mjs
```

**语料规模**：48 个会话 / 236 条有思考的 `assistant/message`；
中文主导 38 条、混合 37 条 → 导出 **75 条中文/混合思考 → 2111 个片段**（中文主导 940 个）。

## 4. 诊断（三个实测结论）

### 4.1 词表一半是空壳 —— 这是 D11 的直接根因

逐词体检（全量 4714 片段）：**56 个词条里 37 个零命中**。

| 桶 | 中文侧原词条 | 实测 DF |
|---|---|---|
| 顿悟 | `原来` `懂了` `想通` `明白了` `知道了` `恍然大悟` | **全部 0** |
| 吐槽 | `哎` `绕了一大圈` `白折腾` `这坑` `无语` `离谱` `居然` `竟然` | **全部 0** |
| 自我怀疑 | `我搞错` `搞错` `反了` `弄错` `看错` | **全部 0**（仅 `等等` 10 / `不对` 1） |
| 犹豫权衡 | `权衡` `纠结` | **全部 0**（`还是` 14 / `要不` 8 有效） |

英文侧同样有 20 个僵尸：`tricky` `makes sense` `got it` `ugh` `that's the issue` `turns out` `unsure` `trade-off`…

⚠️ **连单测护栏例句都建在零命中词上**（`哦——原来 param 是必填的`）。

### 4.2 中英"有戏"不是一个体系

| | 英文侧 | 中文侧 |
|---|---|---|
| 主要形态 | **情绪词** | **自语式判断 / 转折** |
| 实测高频 | `actually` 282 · `hmm` 208 · `wait` 84 | `结论` 51 · `说明` 48 · `其实` 22 · `待实测` 12 |
| 情绪词 | 稀疏但存在 | **几乎不存在**（`哎`/`无语`/`离谱`/`纠结` 全 0） |

中文原文样例（本机诊断，不入库）：
`其实先别乱跑命令` · `不过等一下，还有一点值得确认` · `结论：当前用的是官方账号通道`
`其实上面两条命令都完全没输出…说明 shell 启动就失败` · `置信度：中（11.3 是脚本注释值，未实测复算）`

### 4.3 有效词条清单（DF≥5 才收）

| 桶 | 新增中文词（DF） |
|---|---|
| 自我怀疑 | 其实(22) · 实际上(13) · 待实测(12) · 等等(10) · 未实测(5) · 疑点(5) |
| 顿悟 | 结论(51) · 说明(48) · 根本原因(9) |
| 吐槽 | 坑(13) |
| 犹豫权衡 | 嗯(28) · 不过(27) · 或者(19) · 值得(15) · 还是(14) · 除非(8) · 要不要(7) · 至少(5) · 或许(5) · 要不(8) |

## 5. 结果

| 指标 | 现行（英文校准） | **本轮（中文重校）** | 判据 |
|---|---|---|---|
| **中文语料过阈率 ≥0.50** | **4.4%** | **10.4%** | DESIGN §5.1「降噪 ~90%」 |
| 全量语料过阈率 | 7.6% | 9.3% | 同量级 |
| 中文语料最高分 | 0.87 | **1.00** | —— |
| 正例护栏（5 条，中英各半） | —— | **5/5 全过** | 强信号必须能过闸 |
| 噪声护栏（代码/路径/符号） | 0.00~0.26 | **0.00~0.26（不变）** | 必须 <0.3 |
| 单测 | 19 例全绿 | **19 例全绿** | —— |

阈值 **保持 0.50 不动** —— 因为归属诊断显示：未过阈的 87% 是"命中但不够"，
而加词后这一批自动上来了，不需要靠降阈值凑数量。
